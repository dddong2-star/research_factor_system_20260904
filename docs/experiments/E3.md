# E3：市场与绩效融合路由

## 目的

检验在市场信息之外加入因子自身的历史表现，是否能改善代表因子的动态权重。

## 输入

继承 E2 的市场特征，并为每个代表因子构造 9 维滚动绩效输入：

- IC、Rank IC、slope 各自的均值、标准差和信息比率。
- 窗口由 `step4 run --rolling-window` 控制，默认 `40` 条成熟记录。
- 没有可用历史特征的位置在输入张量中置零。

训练目标仍为训练期日度 `rank_ic`。聚类、测试起点和候选因子来自 `--cluster-run`。

## 是否使用模型

使用一个 `FactorRouter`。市场分支和绩效分支分别输出分数，再由可学习的 `alpha = sigmoid(alpha_logit)` 融合为 `fused_scores`，最后经 Softmax 生成稠密因子权重。

## 与前级差异

E3 在 E2 的市场路由上增加滚动绩效分支及可学习融合系数。它仍不使用 Gumbel Top-k，也不加入换手惩罚。
