# E2：市场感知路由

## 目的

检验每日市场信息能否比 E1 的静态等权更有效地分配代表因子权重。

## 输入

与 [E1](E1.md) 相同，并实际使用 `market_states.parquet` 中的四个数值特征：

- `market_return`
- `market_volatility`
- `up_ratio`
- `cross_section_dispersion`

训练监督目标是训练期各代表因子的日度 `rank_ic`。`--epochs` 和 `--random-state` 由 `step4 run` 提供。

## 是否使用模型

使用一个 `FactorRouter`，隐藏维度固定为 `32`，Adam 学习率固定为 `0.01`。E2 将绩效输入置零并只使用 `market_scores`；模型输出经 Softmax 转为所有代表因子的稠密权重。

## 与前级差异

在共用步骤 3 代表因子池和成本回测之上，E2 将等权替换为市场特征驱动的动态权重。它不使用滚动绩效特征，不启用 Gumbel Top-k，也不加入换手惩罚。

## 产物

套件公共产物与 E1 相同。`E2\` 内包含：

- `config.json`
- `model.pt`
- `factor_weights.parquet`
- `alpha.parquet`
- `daily.parquet`
- `metrics.json`

```powershell
python -m research_pipeline step4 run `
  --cluster-run .\research_runs\cluster_<run_id> `
  --experiments E1,E2,E3,E4
```
