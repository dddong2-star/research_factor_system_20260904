# E4：稀疏路由与换手惩罚

## 目的

在 E3 的市场—绩效融合路由上检验稀疏代表因子选择和因子权重变化惩罚的作用。

## 输入

与 E3 相同，并增加 `step4 run --factor-top-k`。省略该参数时，代码将其设为代表因子数，此时不会产生实际稀疏化；若要观察 Top-k 差异，应设置为小于代表因子数的正整数。

## 是否使用模型

使用一个 `FactorRouter`，同时使用市场和滚动绩效分支：

- 训练阶段对 `fused_scores` 使用温度固定为 `0.5` 的 Gumbel Top-k mask。
- 训练损失额外加入系数固定为 `0.01` 的换手惩罚项。
- 推理阶段采用确定性 Top-k，将未选分数屏蔽后再做 Softmax。

## 与前级差异

E4 在 E3 基础上增加 Gumbel Top-k、推理期确定性 Top-k 和简化的因子权重换手惩罚。股票 Alpha、下一交易日执行和成本回测逻辑不变。

## 产物

`E4\` 内包含：

- `config.json`
- `model.pt`
- `factor_weights.parquet`
- `alpha.parquet`
- `daily.parquet`
- `metrics.json`

套件根目录的 `experiment_suite.json` 汇总本次实际运行的 E1–E4 配置、指标和目录。换手惩罚的近似范围见 [已知限制](../reference/limitations.md)。

```powershell
python -m research_pipeline step4 run `
  --cluster-run .\research_runs\cluster_<run_id> `
  --experiments E1,E2,E3,E4 `
  --factor-top-k 3
```
