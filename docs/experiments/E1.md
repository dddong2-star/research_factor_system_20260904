# E1：K-Means 代表因子等权基准

## 目的

建立最简单、可解释的成本回测基准：使用步骤 3 已经选出的代表因子，让它们每日等权。E1 用来判断后续动态路由是否真正带来增益。

## 输入

- `step4 run --cluster-run`：步骤 3 写出的聚类运行目录。
- 清单中已绑定同一 `snapshot_id` 的行情、因子值和市场状态。
- 回测参数由 `step4 run` 提供：`--top-n`、`--fee-rate`、`--slippage-rate`。

E1 本身不使用市场状态路由。测试起点、簇数和代表因子在 `step3 cluster` 中确定。

## 是否使用模型

不训练 `FactorRouter`。K-Means 已在步骤 3 完成；每个代表因子的最终权重固定为 `1 / 代表因子数`。

## 与前级差异

E1 是起始基准。它只做代表因子等权、股票 Alpha 合成、下一交易日执行和含手续费/滑点回测，没有市场路由、绩效路由、Top-k 或换手惩罚。

## 产物

套件根目录从步骤 3 复制 `daily_factor_performance.parquet`、`behavior_features.parquet`、`factor_clusters.parquet` 和 `clustering.json`。`E1\` 内包含：

- `config.json`
- `factor_weights.parquet`
- `alpha.parquet`
- `daily.parquet`
- `metrics.json`

E1 不生成 `model.pt`。

```powershell
python -m research_pipeline step4 run `
  --cluster-run .\research_runs\cluster_<run_id> `
  --experiments E1,E2,E3,E4
```

字段和目录说明见 [产物参考](../reference/artifacts.md)。
