# 已知限制

以下内容按当前代码行为记录，不代表未来设计目标。正式研究前应评估其对结论的影响。

## 数据与快照

- 快照默认按目录约定为不可变，但 `step1 export --overwrite` 会删除并重建同名快照；操作不当会破坏可复现性。
- 下游运行只在输入清单存在时核对 `snapshot_id`。缺失运行清单时，`check_snapshot` 会跳过编号校验；运行前应主动执行 `step1 validate` 并保留清单。
- `step1 validate` 校验六张表、部分必需列、行情/股票池唯一键和清单哈希，但不会验证所有列的数据类型、因子编号唯一性或业务合理性。
- 因子表达式逐个计算；失败分区被记录并跳过，因此不同 `step2 values` 运行可能拥有不同的有效候选池。

## 时间边界与潜在泄漏

- 未来收益通过每只证券内 `shift(-horizon)` 计算，`horizon` 实际是交易记录步数。
- `label_available_date` 当前却使用 `date + horizon 个日历日`。两者口径不一致；例如 20 个交易日标签通常晚于 20 个日历日成熟，滚动绩效特征可能过早认为标签可用。
- 聚类行为摘要要求 `date < test_start` 且 `label_available_date < test_start`，但仍受上述日历日口径影响。
- 路由训练的有效掩码只检查 `date < test_start` 和目标非空，没有再次要求该日未来收益标签在测试起点前成熟。因此测试边界前最后 `horizon` 个交易记录的监督目标可能引用测试期价格。
- 当前没有独立验证期或自动超参数搜索。`step4 run` 只做训练期/测试期切分；根据测试结果反复选参会造成测试集污染。

## 市场状态与模型

- 主运行器给 `FactorRouter` 输入的是当日四维市场特征，不是过去 40 日市场状态序列；模型中的时间注意力接口尚未接入 E1–E6。
- 市场状态是规则标签，不是学习模型。`fit_window_end` 写为整张状态表的最大日期，不表示滚动拟合边界。
- 路由器在整个训练张量上一次性训练，不是 walk-forward 或定期滚动重训。
- 训练目标主要让路由分数拟合日度 Rank IC，尚无组合收益、多任务目标或容量约束。E2–E4 没有负载均衡；E5、E6 外层在训练集平均 Softmax 上附加均匀项，系数 0.01。E6 内层仍不加。
- 无历史绩效的 E3/E4/E6 输入位置会置零，模型无法区分“真实零表现”和“没有可用历史”。
- 模型文件只保存 PyTorch `state_dict`，未保存优化器、运行环境、依赖版本或完整可直接加载的模型对象。
- 当前训练未提供设备参数，默认在 PyTorch 默认设备上执行；大因子池和 E6 的多个内层模型可能耗时、耗内存。

## 各实验边界

- E1–E4 只用每簇代表因子合成 Alpha；E5、E6 才重新使用完整因子群，比较时应明确候选空间不同。
- E4 的训练期换手项是研究骨架：代码将各日期权重与一个共享 `previous` 基准比较，并在每轮结束后更新为最后一个日期的权重，不是严格按相邻交易日递推的换手损失。
- E4 的换手惩罚约束因子权重，不直接约束最终股票持仓；真实回测成本可能与训练代理目标不同。
- E4 省略 `--factor-top-k` 时，Top-k 等于代表因子数，不产生稀疏效果。
- E5、E6 运行时都把人数小于 3 的簇并入最近的足够大簇，再训练外层；步骤 3 目录仍是原始簇。E5/E6 写出的 `factor_groups` 是合并后的群。
- E5 外层先产生稠密代表因子 Softmax 权重，再用 `argmax` 硬选一个群；外层权重大小不会继续缩放最终群内权重。
- E6 外层主簇必须停留 20 个交易日才允许切换；当前关掉 Top-2，每天只用主簇（`soft_top_k=1`，`group_weight=1`）。最短停留按外层日期轴的交易日计数，含训练期。
- E5 选中群内始终等权。E6 内层始终对主簇全部因子做稠密 Softmax；两者都没有 `factor-top-k` 参数。
- E6 为每个**合并后的**簇在全部训练日期上分别训练内层模型，模型数为 `1 + K'`；这不是按外层实际选中日期训练。

## 条件评价与选择

- 条件评价按日期比例切分，不支持用户直接指定切分日期；最后 `horizon` 个日期可能因未来收益缺失而减少有效样本。
- `step2 select` 的打分固定为 `0.7 × rank_ic_mean + 0.3 × icir`，没有 CLI 权重参数。
- `run_selection` 当前没有把因子值传入相关性计算，因此 `--correlation-threshold` 虽被记录，CLI 实际不会执行互相关剔除。
- `step2 select --split test` 在语法上允许，但会直接使用测试期指标选因子；若目标是无偏测试，不应这样使用。

## 回测与交易约束

- 回测为 Alpha 排名前 `top_n` 的多头等权组合，不支持空头、行业/风格中性、基准约束或风险预算。
- 信号在下一交易日执行，收益使用收盘价序列近似；没有开盘成交价、盘中成交过程或订单撮合。
- 只处理停牌冻结，尚未统一处理涨跌停、ST、退市、上市天数、成交量容量和冲击成本。
- 成本模型固定为 `turnover × (fee_rate + slippage_rate)`，不区分买卖方向、印花税、最低佣金或动态滑点。
- 当前换手是权重绝对变化之和，没有除以 2；解释费率和其他系统对比时需保持口径一致。
- 指标按 252 个交易日年化，不处理无风险利率、基准超额收益或统计置信区间。

## 结果解释

- 固定随机种子可提高单次可复现性，但当前流程不自动进行多随机种子重复实验或置信区间估计。
- 运行目录哈希不覆盖所有代码和依赖版本；同一配置在代码变化后仍可能得到相同哈希后缀。
- 历史烟雾运行只能证明链路可执行，不能证明收益有效或模型优于基准。
